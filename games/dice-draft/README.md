# Dice Draft

You and a rival are dealt the same eight rolls of three dice, one at a time. Place
each roll in one of your eight bet zones. It stays there. When the table is full,
every zone pays by its own rule and the higher total wins.

```bash
npm start dice    # from the repo root
npm test dice
```

| Zone | Scores when | Pays |
|---|---|---|
| Small | Total 4–10, no triple | 2 pts per pip under 11 |
| Big | Total 11–17, no triple | 2 pts per pip over 10 |
| Triple | All 3 dice match | 30 pts |
| Double | Any two dice match | 10 pts |
| Straight | 3 in a row | 15 pts |
| Sixes | Each 6 rolled | 4 pts per 6 |
| Ones | Each 1 rolled | 4 pts per 1 |
| Total | Any roll | The total |

Tap a zone, drag the dice onto it, or press its number. You have 20 seconds per roll.
